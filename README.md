# Hub de enlaces (links.e-nova.com.co)

Para publicarlo en Vercel desde esta carpeta (Git Bash o terminal):

    npx vercel --prod

Guías y atajos se guardan en el Supabase de AI Plata (tablas hub_guias, hub_atajos y bucket hub).
Solo la cuenta con rol admin en AI Plata puede publicar o borrar, desde el botón "Administrar" al final de la página.
